# MeasureQuest — EE236AI Foundations of Electrical and Electronics Measurements

Gamified course website for EE236AI (Bajaj BEST Initiative), III Semester B.E. (ECE), Section C, AY 2026-27,
Department of Electronics and Communication Engineering, RV College of Engineering, Bengaluru.

Faculty: Dr. Veena Divya Krishnappa

Single-page static site (`index.html`) with interactive labs, quizzes, flash cards, a Watch & Learn library and a
Section C leaderboard. Student sign-in, scores and response-time logs are handled by a Google Apps Script backend.
